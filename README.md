**نظام التأهيب الميداني للمشغل المبتدئ**

## Stack

Vanilla HTML/CSS/JS · RTL Arabic · Google Fonts only · no build step

## Thesis

Novice operators fail from **behavioral** barriers (hesitation, sequence why, correcting a superior) — not from lack of syllabus knowledge.
